# Drawing-convention learning ledger

Read-only inspection of Slip Robotics drawings in the PDM vault, done with the fork's
`inspect_drawing` tool (SolidWorks file, not PDF). One entry per drawing; "Patterns so far"
is rewritten at the end of each batch. Standard / skill / memory are updated only after all
167 drawings are done.

Scope (167 drawings):
- TRAY AND T-BOT SOLUTION\MODULES: CHASSIS 32, MOTOR MODULE 26, UI - COMMUNICATIONS MODULE 22, EXTERNAL COVERS 28
- Arch 3.0\MODULES: CHASSIS 30, MOTOR MODULE 2, EXTERNAL COVERS 27

Batch plan: 30 per batch, Simón gives the go for each. Order: Tray CHASSIS → Tray MOTOR MODULE →
Tray UI/COMMS → Tray EXTERNAL COVERS → Arch 3.0 CHASSIS → Arch 3.0 MOTOR MODULE → Arch 3.0 EXTERNAL COVERS.

Entry format:
`PN | title | EOR / approved | rev | part type | sheets | views (type, link, config, display) | dims (what, attached to) | notes / tables | remarks`

## Patterns so far (after batch 1 — Tray CHASSIS)

**Sheet / template.** Every drawing is D-size (863.6 × 558.8), third angle, template `FORMAT SR SHT1 D 2025.slddrt` for sheet 1 and `format sr sht2+d 2025.slddrt` for continuation sheets. Sheet scale is set per drawing (2:1 for tiny parts up to 1:16 for the chassis weldment); the *views* carry their own scale (1:1, 1:2, 1:3.25, 1:4 …) — `SCALE: NONE` is printed in the title block.

**View structure (parts).** One base **model view** (`AbsoluteView`, orientation `*Front/*Back/*Left/*Right/*Top/*Bottom`, often rotated 90° so long parts lie along the sheet), and every other orthographic view is a **projected view** (`UnfoldedView`) from it — including the thin edge view that carries the (thickness). Several drawings have an edge view with no base and the main view projected from *it* (the original base was replaced) — still all linked. Iso view = separate model view `*Isometric` (sometimes `*Trimetric`), usually small (1:4–1:8 relative), placed top-left or right; on some drawings it is parked off-sheet (x < 0) and doesn't print. Tangent edges: **visible on iso views, removed on orthographic views** (a few base views leave them visible). Flat-pattern views are model views of orientation `Flat pattern` referencing configuration **`<cfg>SM-FLAT-PATTERN`** on a second sheet, with SolidWorks bend notes (`UP 90° R .25`) and sometimes rotated 90°.

**Dimensioning (plates).** Overall length + width on the main view; **(thickness) in parentheses** on the edge view; then ONE located hole (X from end, Y from edge, Ø) — or nothing at all when the plate is trivial (2×2 reinforcement plates) or when it is a big hole-field plate (107172/107173: overall only, CAD file governs). Hole-wizard holes get **full hole callouts** (`2X Ø.266 THRU ALL` / `⌵ Ø.507 X 82°`; tapped `10-32 UNF THRU ALL` / `2X Ø.159 THRU ALL`); plain cut holes get `Ø.xxx` (sometimes with `6X` prefix). Where a plate has many mating holes (107096, 107143/44) the convention switches to **ordinate chains from one corner** + hole callouts per size. Reference overall dims in parentheses when the size is driven by a mating part (107159: (52.99), (7.4375)). Chamfers get a chamfer dimension (`0.125 X 60°`).

**Dimensioning (bent parts).** Main view: overall + one located hole. Each projected face view: one located hole on that face (X, Y, Ø). End view: flange length(s), **(R.25) bend radius in parentheses**, (thk). Flat sheet: flat overall (L × W) + edge-to-bend-line distance(s); nothing else. Material note carries "(0.25 IN BEND RADIUS)" after the thickness on some drawings.

**Weldments.** Sheet 1: iso (tangent visible) fully ballooned with split item/qty balloons (style 7), BOM table (`ITEM NO. | PART NUMBER | TITLE | MATERIAL | [THICKNESS] | QTY. | REVISION`), revision table, `WELDED ASSEMBLY DRAWING` title-block label, notes "MATERIAL: SEE CUTLIST ON SHEET [1]", AWS D8.x weld spec, mask/plug/grind instructions. Dimensions only for overall/critical positions (16.0; 91.55; 164/53/17.75…). Weld symbols sit on **projected views, section views (A-A…) and detail views**, never on the iso. Big weldments: one sheet per region (base view → sections → details 1:4…1:1 with welds + balloons).

**Revision handling.** Revision table is a **General Table** (DESCRIPTION | date | APPROVED BY | REV) that grows a row per revision (some early rows still carry `$PRP` links). Changed features are flagged with **hexagon balloon notes (style 3) with leaders showing "7"** (= note 7 "WHERE SHOWN '7' … MODIFICATION … UNDER LATEST RELEASED REVISION") plus adjacent quantity notes (`6X`, `10X`). Some drawings use a plain note or a circle balloon for the same flag.

**Notes block.** Two variants: (a) template with a separate "1. 2. … 7." numbering note + text note; (b) single auto-numbered note (weldments). Common items: Y14.5-2018 (+ "ALL DIMENSIONS ARE IN INCHES UNLESS OTHERWISE SPECIFIED"), MATERIAL: `$PRPSHEET:"MATERIAL", $PRPSHEET:"THICKNESS" IN THK[, (R IN BEND RADIUS)].`, FINISH: `$PRPSHEET:"FINISH"` (no period), BREAK AND DEBURR…, PARENTHESIS = REFERENCE, CAD FILES SUPPLEMENT (bold PN-REV), revision-flag legend. Title-block fields are all property-linked (`ENG OF RECORD`, `APPROVED BY`, dates, `MODULE_MANUAL`/`COMPONENT_MANUAL` = CC / M or W).

**Added after batch 2 (Motor Module, mostly Aug–Dec 2025).** (1) *Machined round parts* (pins, bushing housings, shafts): end model view + a **Section A-A** carrying all dims — Ø features, (Ø stock) in parentheses, chamfer angles as reference (135°/45°), `4X` prefixes, one centerline; long shafts add a Detail view (4:1) for the end chamfer and the overall-with-chamfers in parentheses; material note names the stock form ("1.375" AISI 1045, COLD WORKED ROD", "1" TURNED, GROUND, POLISHED … KEYED SHAFT"). (2) *Machined plastics* (Delrin spacer): iso + main view + projected + Section, csk callouts. (3) *COTS spec drawings* (mecanum wheel, TYPE=COTS): envelope + interface dims, section + detail, plus a separate SPECIFICATIONS note block; rev table header DRAWN BY. (4) *Top-level assembly drawings* (TYPE ASSEMBLY, "ASSEMBLY DRAWING" label): iso + BOM only; *hardware-install assemblies* (PEM nuts): one sheet per hardware type with "INSTALL nX … PEM NUTS IN THE CENTER MARKED HOLES" leader note + balloons. (5) *Weldment dims are reference*: every overall on a weldment view is in parentheses ((16.0625), (20.75)…); welds go on sections/details; a "TOP" label and "SEE NOTE n" leaders are common; rivnuts/PEM nuts appear as BOM items with McMaster P/N in the PART NUMBER cell. (6) *Ordinate chains* are the standard answer to any hole field — on the main view or on a separately projected far-face view (106981, 106987 chain a third projected view off a projected view). (7) *Older-era differences* (2025): flat-pattern dims in parentheses, ordinate bend-line chains in parentheses, circle balloons (style 1) instead of split balloons, plain "3/8-16 Tapped Hole" leader notes instead of hole callouts, iso alone on sheet 1, revs "1"/"1.1"/"##"/"X", `<T#-n>` glitches in the numbering note, "FINISH: NONE, NONE" (FINISH + FINISH_COLOR both linked). 2026 drawings dropped all of these.

**Added after batch 3 (UI/COMMS + first External Covers).** (1) **FACE A convention confirmed in SolidWorks** (107496, 108292, 108438, 108440): the inclined face gets an angular dim + a "FACE A" leader note on the ortho/projected view; the normal view is a **model view of orientation `Current Model View`** (AbsoluteView — not an auxiliary view), same scale as the main view, rotated as needed (0° / 270°) to sit upright, tangent edges visible (108440: removed), labelled with a plain note "FACE A - NORMAL VIEW" below it, carrying the one located feature (X, Y, Ø). Two inclined faces → FACE A and FACE B, one normal view each. (2) **3D-printed PETG/PET parts** are drawn exactly like plates (iso + main + projected faces, overall + one hole per face, wall sizes as needed) with no thickness dim; MATERIAL note "PETG, WHITE" etc.; THICKNESS prop often left unresolved. (3) Thin 5052 0.063 camera brackets (108070, 108143, 107372): main view carries several holes/Øs (small parts get more than one feature per face when they are all mating features); flat sheet = overall + bend lines as **linear symmetric pairs** or an **ordinate chain (2026 form: no parentheses)**. (4) First **R00** releases appear in May 2026 (108143) — R00 = initial release convention from then on. (5) Reference overall in parentheses when driven by the mating assembly (107372 (4.875)). (6) **S. KOVAR's cover drawings are a different dialect** — everything ordinate (hor/vert chains, centerline `<MOD-CL>` origins), thickness shown as a `0 / 0.0598 STOCK` ordinate pair, "ISOMETRIC VIEW"/"FLAT PATTERN" labels, iso alone on sheet 1, balloon-note flags "8", gauge-based material notes, prototype revs P01…P11 then "ENG RELEASE Pnn = R01" — recorded for context, not adopted.

**Added after batch 4 (rest of External Covers + first Arch 3.0 CHASSIS).** (1) Cover/kit dialect (Kovar) fully catalogued: KIT drawings (TYPE KIT, K - KIT) with hardware item numbers ≥100, "n PL" quantity balloons, gasket-placement and label-installation sheets; decals (D - DECAL, module SM) with vinyl material notes; INSEPARABLE ASSEMBLY DRAWING for PEM-nut sub-assemblies with the child part's views re-used and overall dims in parentheses; PVC/ABS/PETG covers; P-revision prototypes with PLM "auto bump" rows. None of it changes Simón's standard, but the *categories* (KIT, DECAL, PEM ASSY, INSEPARABLE ASSEMBLY) exist in the title-block vocabulary. (2) Simón's own 107057 and Dziak's 108703 inside that folder follow the plate pattern (linear dims, one located feature, edge (thk)); Dziak leaves thickness un-parenthesised and adds more locators. (3) **Arch 3.0 (2023–2025) = the previous template generation**: SolidWorks stock B-size title block, real Revision Table (revs 1, 2, 3), material as a free note, ±1° / ±.06 / ±.02 / ±.005 tolerance block, CC-M/CC-W numbering; but the view grammar (model view + projected, small iso, flat pattern sheet with overall + bend-line dims, one located hole per face, (section) in parentheses on tubes, rev-flag leaders) is already the same — the 2026 standard inherited it and added: D-size SR template with property-linked title block/notes, General-Table revision block, R00/R01 revs, hexagon rev-flag balloons, (thk) parentheses, hole callouts.

**Added after batch 5 (rest of Arch 3.0).** (1) The FACE A idea is Simón's own and dates from **Jan 2024** (CE-M240119-15/16: "FACE A" note + `Current Model View` + "NORMAL VIEW TO FACE A - DETAIL"); by Jul 2026 it is the direct labelled normal view. (2) 2024–25 flat patterns by Simón use **overall + ordinate chain of bend lines** (LED brackets), 2026 ones use linear bend-line dims or an ordinate chain — both unparenthesised; Dziak/Cheedalla put the flat on sheet 1, Simón on its own sheet. (3) Long bent brackets (49–70") carry the **overall in parentheses** on the long view when the length is derived (LED brackets, edge guards, CC-M240726-11/12). (4) Machined plates (MM-M240804-11): counterbore callouts with depth symbol, section for bores, "2X R.020 MAX" leader. (5) Weldment grammar confirmed across three generations (CC-W240711-11 2024 → 106181 2026; CC-W240812-81 Dziak): iso+BOM sheet; base→section→detail region sheets with welds; "NO WELD" zones as a dimension with "NO WELD" suffix + "NO WELD PAST THIS POINT" note; masked-hole sheets ("THIS SHEET IS PROVIDED TO LOCATE MASKED HOLES IN THE CHASSIS."). (6) Jakomin's Oct 2025 revisions add basic dims and ±0.010 tolerances on critical hole callouts. (7) Team dialects: Kovar = ordinate-everything covers; Dziak/Cheedalla = Simón's grammar but tangent edges left visible, flat on sheet 1, more dims (106370: seven Ø callouts on one view), template glitches (`<T#-5>`), thickness unparenthesised; Won = mixed. The standard to encode is Simón's 2026 form; everything else is context.
